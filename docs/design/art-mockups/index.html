Lantern Village art direction

Mockups for a richer 2D look on phones. Everything here is still inline SVG and CSS gradients: no image files, so it works offline, stays small, and every drawing can still be generated from data the way the game draws portraits and backdrops today.

Before and after

The same village backdrop. Today it is three flat silhouettes; the proposal paints it in layers: sky, moon and cloud, far hills in haze, the Lantern Tower, valley mist, lit townhouses, lantern strings, and a sakura bough in front.

On the phone

Three screens at 390px: the village you arrive in, a fight mid-exchange, and a sensei’s sheet. The art sits behind the interface; the existing tokens, fonts and paper surfaces stay.

Portraits

The woodblock key line stays, but faces get proper eyes (iris gradient, catchlights, lids), cel shadows under the fringe and jaw, a warm rim light from the lanterns, and outfits by role. Each part is still a swappable layer, so Appearance can drive them.

Places in the wider country

Each land gets its own palette and light, so travelling feels like arriving somewhere.

Icons

Two-tone drawings in the same ink line as the portraits, readable at 24px and rich at 48px. Shown on the lacquer tile used for place cards, with the small sizes below.

Keeping it fast on a phone

Glow without blur. Every lantern glow, halo and fire burst is a radial gradient. No feGaussianBlur or feTurbulence, which are the filters that make mobile Safari stutter.

Generated, not hand-placed. Ridgelines, stars, blossoms, bamboo and roof tiles come from a seeded generator, the same way the game already draws from its seed. A backdrop is a few kilobytes of code rather than a large asset.

Layers you can move. Each scene is built back to front (sky, far hills, middle ground, street, foreground), so the hub can drift its layers a few pixels on scroll or tilt, and the sky can still change by time of day through the existing .sky[data-slot] classes.

Same rules as the UI. Colours come from the token palette, numbers stay in chips, labels are sentence case, and there are no image files, so it all still works offline.
